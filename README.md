# SaiKet Systems Python Development Internship

Six Python projects completed for the SaiKet Systems internship program.

| Task | Project | Skills | Run |
|---|---|---|---|
| 1 | To-Do List (console + GUI) | Data structures, conditionals | `python task1_todo.py` / `python task1_todo_gui.py` |
| 2 | Guess the Number (console + GUI) | Random numbers, loops, conditionals | `python task2_guess_number.py` / `python task2_guess_gui.py` |
| 3 | File Handling | File I/O, string manipulation, exceptions | `python task3_file_handling.py` |
| 4 | Web Scraper | Requests, Beautiful Soup, HTML parsing | `python task4_web_scraper.py` |
| 5 | Currency Converter (console + GUI) | API integration, input handling | `python task5_currency_converter.py` / `python task5_currency_gui.py` |
| 6 | Word Count Tool | File I/O, regex, data analysis, Matplotlib | `python task6_word_count.py sample_text.txt` |

Each task lives in its own folder. Run commands from inside that folder.

## Setup

```powershell
pip install requests beautifulsoup4 matplotlib
```

Task 5 needs an exchange-rate API key. Set it as an environment variable
instead of putting it in the code:

```powershell
$env:EXCHANGE_API_KEY = "your_key_here"
```
